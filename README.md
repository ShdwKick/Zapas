# Что у нас есть?

Учёт того, что лежит дома и у чего есть срок. Первый раздел — домашняя
аптечка: что есть, когда истекает, где лежит, сколько осталось.

План целиком, с причинами решений — [ARCHITECTURE.md](ARCHITECTURE.md).
Сделаны **этапы 1–4**: ручной учёт со сроками и местами, сканирование кода
с упаковки (DataMatrix МДЛП и EAN, каталог по GTIN, дедуп коробки по
серийному номеру), справочник из официальных инструкций с проверкой цитат,
общий дом с приглашениями из друзей BurningHouse и напоминания о сроках.
Дальше — второй раздел: гигиена и бытовая химия.

**Сервис ведёт учёт и ничего не советует о применении.** Ни показаний, ни
дозировок: только то, что написано на упаковке, и ссылка на инструкцию. Это
решение, а не недоделка — см. ARCHITECTURE.md, «Граница».

## Запуск

Зависимостей нет: сервер на встроенных `node:http` и `node:sqlite`, нужен
Node 24+.

```bash
node server.js
```

Откроется на `http://localhost:8799`. Без переменных окружения вход
недоступен, и сервис работает как гостевой — вся аптечка живёт в
`localStorage` браузера. Этого достаточно, чтобы потрогать всё, кроме
общего дома.

С входом (локальный auth на 8792):

```bash
AUTH_ISSUER=http://localhost:8792 AUTH_CLIENT_ID=zapas node server.js
```

| Переменная | Зачем |
|---|---|
| `AUTH_ISSUER` | адрес auth, **символ в символ** как его `ISSUER` |
| `AUTH_CLIENT_ID` | `zapas` |
| `ADMIN_INTERNAL_KEY` | общий ключ с Admin: `/internal/*` и уборка удалённых аккаунтов |
| `DATA_DIR` | куда класть `zapas.db` и ключи VAPID (по умолчанию `./data`) |
| `PUBLIC_URL` | адрес для ссылок в уведомлениях |
| `VAPID_SUBJECT` | контакт отправителя push, обычно адрес сервиса |
| `PORT` | 8799 |

## Тесты

Обычные скрипты с кодом возврата, без зависимостей и без сети:

```bash
node test/expiry.test.mjs && node test/gs1.test.mjs && node test/leaflet.test.mjs && node test/home.test.mjs && node test/store.test.mjs
```

- `expiry` — правила сроков: конец месяца, вскрытие, пороги подсветки, порядок.
- `gs1` — разбор кода с упаковки: DataMatrix МДЛП, EAN, контрольная цифра,
  сканеры без разделителя.
- `leaflet` — разбор инструкций: поиск цитаты в тексте PDF и отбор полей.
  Главная проверка: поле с выдуманной цитатой не проходит.
- `home` — общий дом и напоминания: приглашения, права, выход, кому и о чём
  напоминать, дедуп по упаковкам.
- `store` — хранилище на временной базе: дом, места, позиции, упаковки,
  журнал, отмена, поиск по коду, дедуп по серийному, подсказки из
  инструкций, перенос гостевой аптечки, удаление данных.

Камеру тесты не трогают: распознавание — чужой код, он проверяется один раз
руками на настоящей упаковке (см. ниже).

## Справочник из инструкций

Запускается руками, на своей машине, и его результат коммитится как часть
образа — в рантайме ни сети, ни ключа GigaChat не нужно.

```bash
GIGACHAT_CA=/tmp/ru-bundle.pem GIGACHAT_AUTH_KEY=... node tools/leaflet.mjs ./pdf
```

Корневой сертификат Минцифры обязателен: GigaChat подписан им, а в системных
хранилищах его нет. Как его взять — в шапке `tools/leaflet.mjs`. Проверку
сертификата инструмент не отключает.

Каждое поле он берёт только вместе с дословной цитатой и **ищет эту цитату в
тексте PDF**; не нашёл — поле не попадает в справочник. Сканы без текстового
слоя пропускаются: сверять не с чем, а придумывать нельзя.

**Сканер нужно один раз проверить на телефоне** — на настоящей коробке с
DataMatrix и при плохом свете. В браузерной панели камеры нет, а эмулятор
проверяет что угодно, кроме того, что важно: читается ли мелкий код с
мятой упаковки.

`brand.css`, `brand.js`, `admin-internal.js`, `set-env.sh` — копии из
`Shared/`, **здесь их не редактируют**: правки вносят в `Shared/` и
раскладывают `node Shared/sync.mjs`.

Иконки приложения получены из `assets/icons/icon-src.svg`. Фавикон —
отдельный файл с вписанными цветами: в нём CSS-переменные не работают вовсе.

## Выкатка

Пошагово, с проверками и граблями — **[deploy/README.md](deploy/README.md)**.
Коротко: пуш в `main` → GitHub Actions собирает образ и кладёт в Docker Hub →
Watchtower на сервере забирает его сам. SSH-ключей в секретах нет.
nginx ставится скриптом: `sudo bash deploy/install-nginx.sh`.

Один раз зарегистрировать клиента в auth:

```bash
docker compose exec auth node server.js client-add zapas "Что у нас есть?" https://zapas.burninghouse.ru/
```

`redirect_uri` сверяется побайтово — лишний или пропущенный слэш ломает вход.
